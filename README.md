# SuperJump - 涂鸦跳跃

一个使用纯前端技术（HTML5 Canvas + JavaScript）实现的涂鸦跳跃（Doodle Jump）风格小游戏。

## 特性

- 🎨 **手绘涂鸦风格**：所有图形使用 Canvas 动态绘制，模拟手绘抖动线条效果
- 🎵 **动态合成音效**：使用 Web Audio API 实时合成音效，无需任何外部音频文件
- 🎮 **经典玩法**：自动跳跃、平台弹跳、穿墙、道具收集、怪物躲避
- 📱 **自适应画布**：自动适配浏览器窗口大小，保持固定游戏比例
- 💾 **本地最高分**：使用 localStorage 保存最高分数
- 🚀 **零依赖**：无需安装任何第三方库或构建工具，开箱即玩

## 操作方式

| 按键 | 功能 |
|------|------|
| `←` / `A` | 向左移动 |
| `→` / `D` | 向右移动 |
| `Space` / `Enter` | 开始游戏 / 重新开始 |
| `P` | 暂停 / 继续 |
| `H` | 打开 / 关闭说明页面 |
| `L` | 切换语言 (中文 / English) |

## 游戏元素

### 平台类型
- 🟢 **绿色平台**：普通固定平台
- 🔵 **蓝色平台**：左右移动平台
- 🟤 **棕色平台**：踩一次后碎裂消失
- 🟣 **紫色平台**：踩后 2.5 秒闪烁消失
- 💗 **粉色平台**：弹力平台，跳得超高

### 道具
- 🔶 **弹簧**：踩到后跳得更高
- 🚀 **火箭**：短时间极速上升
- 🛡️ **护盾**：免疫一次怪物伤害
- 🪙 **金币**：收集获得额外分数
- 🧲 **磁铁**：6 秒内自动吸附附近金币
- ⭐ **双倍分数**：8 秒内分数翻倍
- 🪂 **降落伞**：5 秒下落速度减半

### 障碍物
- 🛸 **UFO**：紫色飞碟，水平飞行
- 👾 **怪物**：绿色小怪物，左右移动
- 🌀 **黑洞**：从上方缓慢下坠的紫色漩涡
- 🔫 **炮台**：固定位置朝玩家发射子弹

## 如何运行

直接在浏览器中打开 `index.html` 文件即可开始游戏：

```
双击 index.html
```

或者使用本地服务器（可选）：

```bash
# Python 3
python -m http.server 8000

# Node.js (需安装 http-server)
npx http-server
```

然后在浏览器中访问 `http://localhost:8000`。

## 浏览器兼容性

- Chrome / Edge / Firefox / Safari 最新版本
- 需要支持 HTML5 Canvas 和 Web Audio API
- 推荐 Chrome 或 Edge 以获得最佳性能

## 技术栈

- **HTML5 Canvas**：2D 游戏渲染
- **ES6+ JavaScript**：游戏逻辑（模块化 IIFE 模式）
- **Web Audio API**：动态音效合成
- **localStorage**：本地数据持久化
- **CSS3**：页面布局和响应式适配

## 开发计划

本项目按照以下阶段逐步开发：

1. ✅ 基础框架：Canvas 初始化、游戏循环
2. ✅ 核心玩法：玩家移动、重力、跳跃
3. ✅ 平台系统：生成、碰撞、多种类型
4. ✅ 相机系统：平滑跟随、只上不下
5. ✅ 手绘风格：抖动线条、涂鸦角色
6. ✅ 道具系统：弹簧、火箭、护盾、金币
7. ✅ 怪物系统：UFO、小怪物
8. ✅ 音效系统：Web Audio API 动态合成
9. ✅ UI 界面：菜单、HUD、暂停、结束画面
10. ✅ 背景效果：手绘网格纸、视差云层
